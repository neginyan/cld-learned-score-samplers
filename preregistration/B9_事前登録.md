## 4. 主な仮説 H1(壊れにくさ)— 合否を決めた判定
- **「壊れた」実行の定義**:確率流 ODE、h ≈ 0.002 で、次のどれかに当てはまるもの。
  - |L| > 1
  - 山から遠い点が全体の 1% を超える
  - 有限でない値が出る
- **主な判定(実行単位)**:目盛り X ∈ {diag2, opt1.25, opt5} それぞれについて、壊れた実行の割合が I より小さいかを、フィッシャーの正確検定(片側、α = 0.05)で調べます。8 回対 8 回です。
  - diag2 対 I を**主な比較**とします(B8 で見えた現象そのもの)。
  - opt1.25 と opt5 は副の比較で、2 つに Holm の補正をかけます。
- **頑健さの確認(ネットワーク単位)**:ネットワークの 2 回の実行のどちらかが壊れたら、そのネットワークを「壊れた」とし、4 本対 4 本で同じ検定をします。
  - 4 対 4 では、p ≤ 0.05 になるのは「I が 4/4 壊れ、相手が 0/4」のときだけです(p = 1/70 ≈ 0.014)。3/4 対 0/4 でも p = 0.071 で届きません。**検出力は低い**です。
  - 「H1 が頑健に支持された」と書くのは、実行単位とネットワーク単位の両方で p ≤ 0.05 のときだけにします。実行単位だけが通った場合は、「実行単位では支持、ネットワーク単位では検出力不足で未確定」と書きます。
- 注意:同じネットワークの 2 回の実行は独立ではありません。実行単位の検定は独立を仮定しているので、p 値は楽観的になります。

## 5. 副仮説 H2(粗い刻み)
- 各目盛り・各刻みで、8 回の実行の |L| の中央値をとります。
- **主な量**:h_max = 「その h と、それより細かい刻みすべてで、|L| の中央値が 0.1 以下」となる、格子の中の最大の h。0.002 でも満たさなければ「なし」とします。ODE と (ii) の両方で求めます。
- 予言(判定つき):
  - **ODE では、diag2・opt1.25・opt5 の h_max が、I の h_max 以上になる**(I が「なし」なら、相手が何か一つの h を持てば成り立ちます)。

## 6. スコアの誤差(比べ方の約束)
- 各ネットワークで、それぞれの目盛りの前向きの周辺分布からの点に対して、**Z の座標でのスコア**(s_Z = Pᵀ s_Y)の相対誤差を測ります。
  - e_Z(σ) = E|ŝ_Z − s_Z|² / E|s_Z|²
  - 位置成分だけの e_Z,pos も測ります。
- σ_min ≤ σ ≤ 2σ_min の平均を主な数として、4 つの目盛りを同じ式で比べます。I も B9 のスクリプトで測り直します。
- 合否はつけず、報告のみとします。

## 7. 壊れる仕組み(探索的、合否なし)
- 走らせる前の予想【予想】:P = I では r = 1 < κ_P = 2 なので、G に負の固有値の方向があります(rI − Sym B の固有値 −1)。逆向きの ODE はこの方向でスコアの誤差を広げ、外れ値の種を作る、という予想です。κ_P ≤ r の目盛り(diag2、opt1.25、opt5)では G ⪰ 0 なので、これが起きないはずです。
- 調べ方:
  1. 壊れた実行の外れ値の点について、同じ出発点から正確なスコアの ODE を走らせて比べます。軌道が離れ始めた時刻 σ(差が 0.05 と 0.5 を超えた時刻)を記録します。ODE は点ごとに決定的なので、外れ値の点だけを走らせ直せば同じ軌道になります。
  2. 離れ始めた所で、次を記録します。
     - 学習したスコアの誤差
     - その点の密度(正確な log p_t、一番近い山からの距離 / σ)
     - 逆向きの流れのヤコビ行列の最大実部(学習スコアと正確なスコア)
     - ずれの、G の負の固有方向への成分
  3. 同じ量を、壊れなかった目盛りの典型的な点でも測って比べます。
- 結果がこの予想と合わなくても、そのまま報告します。
